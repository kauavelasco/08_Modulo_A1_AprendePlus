# 📚 Aprender+

A modern educational mobile application developed with **Flutter**, focused on learning through interactive games, logic challenges, memory exercises, and multimedia experiences.

## 🚀 About The Project

**Aprender+** was created as part of a functional mobile development challenge inspired by **WorldSkills standards**, aiming to deliver an engaging educational experience through multiple mini-games.

The application combines gameplay, animations, multimedia interaction, sensors, timers, dynamic interfaces, and customization features.

---

## ✨ Features

### 🧠 QuizMyBrain

A quiz-based challenge game where players test their knowledge by answering multiple-choice questions.

#### Functionalities

* Dynamic question system
* Score counting
* Question progression
* Result feedback
* Responsive interface
* Interactive gameplay flow

---

### 🎵 GeniusPlay

A memory and sequence repetition game inspired by the classic **Simon Says** concept.

#### Functionalities

* Animated color sequence playback
* Audio effects for each color
* Increasing difficulty
* Automatic sequence restart
* Input validation
* Game over handling
* System language integration

---

### 🃏 MemoCheck

A complete memory card game with advanced interactions and customization.

#### Functionalities

* Theme selection
* Dynamic card generation
* Randomized card positioning
* Countdown start system
* Timer and score tracking
* Match / mismatch logic
* Device vibration feedback
* Flip animation effects
* Shake device to shuffle cards
* Custom gallery image support
* Personalized gameplay mode
